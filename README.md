

A personal countdown adventure built with React and Vite.

```sh
npm install
npm run dev
```

## Personalize it

- Update the Pittsburgh / Philadelphia countdown dates and time zone in `src/config.js`.
- Write one note per two-day drop in the `MESSAGES` array in `src/config.js`; leave a slot as `""` until its note is ready.
- Edit the survival-kit items in `CHECKLIST` in `src/config.js`.
- Customize the pixel doctor in `src/Doctor.jsx` and the theme in `src/App.css`.

Read status and checklist ticks are stored in the visitor's browser.
